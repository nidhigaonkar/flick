# Flick - Quick Start Guide

## 🚀 Getting Started in 3 Steps

### 1. Open YouDJ
Open your browser and go to **https://youdj.online/**

### 2. Start Flick
- Launch Flick (it's already running!)
- Click the **START** button in the Flick window
- You should see:
  - Camera feed with your hand tracked
  - YouDJ opens in Chrome (optional)

### 3. Control with Gestures
- **Move your hand** → Cursor moves on screen
- **Point (index finger)** → Click
- **Pinch (thumb + index)** → Click and drag
- **Peace sign** → Right-click

## 🎵 Using it with YouDJ

### Loading a Track
1. Move your hand to position cursor over "Search" or track library
2. **Point** to click and select a track
3. Move cursor over deck's load area
4. **Point** to load the track

### Adjusting Crossfader
1. Move cursor over the crossfader
2. **Pinch** to grab it
3. Move your hand left/right while pinching
4. Release pinch to let go

### Playing a Track
1. Move cursor over play button
2. **Point** to click play

### Adjusting Volume
1. Move cursor over volume slider
2. **Pinch** to grab
3. Move hand up/down while pinching
4. Release to let go

## 🎮 All Gestures at a Glance

| Gesture | Action | Use For |
|---------|--------|---------|
| 🫳 **Open Palm** | Move cursor | Navigation |
| 👆 **Point** | Click | Buttons, selections |
| 🤏 **Pinch** | Drag | Sliders, crossfader, scrubbing |
| ✌️ **Peace** | Right-click | Context menus |
| ✊ **Fist** | Move cursor | Safe navigation |

## 💡 Pro Tips

1. **Practice gestures first** - Try each one before mixing
2. **Keep hand steady** - Smooth movements = smooth cursor
3. **Use pinch for sliders** - Much more natural than clicking
4. **Good lighting helps** - Face a light source
5. **Adjust smoothing** if cursor is too jumpy or too slow

## ⚠️ Safety

**FAILSAFE:** Move mouse to any screen corner to instantly stop control!

## 🐛 Issues?

- **Cursor jumpy?** Improve lighting, use solid background
- **Gestures not working?** Make them more distinct, hold longer
- **Can't click accurately?** Adjust camera position, keep hand steadier
- **Need to stop?** Move mouse to corner OR click STOP in Flick window
